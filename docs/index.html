  2. 02

03 / GOOD TO KNOW

설치 전에 궁금한 것.

접근 거부(WinError 5) 오류가 났어요.

설치기 0.3.12는 클라이언트 0.3.12를 설치합니다. 파일 사용 중 여부를 먼저 확인하고, 필수 모드의 읽기 전용 속성을 백업 후 처리합니다. 기존 게임 폴더를 선택해 다시 설치하세요. 경기 시작·리스폰 후 중앙 선택창에서 1번은 랜덤 무기, 2번은 즐겨찾기, 3번은 수동 선택입니다. 골데·VSS·더블배럴은 우클릭으로 A/B 모드를 전환합니다. G36·바스티온은 우클릭으로 시즈 전개·해제하며, 해제 완료 후 움직일 수 있습니다.

기존 모드가 지워지나요?

다른 모드·설정·월드는 유지합니다. Gunbed Visuals, Gunbed Assets, Fabric API, Nuit와 모드 ID가 같은 파일만 백업 후 교체합니다. 백업은 실제 .minecraft/gunbed-backups에 저장합니다.

런처를 껐는데 실행 중이라고 나와요.

0.3.12 설치기는 백그라운드에 남아 있는 Minecraft Launcher도 자동 종료합니다. Java나 마인크래프트 게임·서버 프로세스는 강제 종료하지 않습니다. 실행 중인 게임 창도 종료한 뒤 설치하세요. 권한이 부족하다는 오류가 나오면 설치기를 관리자 권한으로 실행하세요.

버전별로 게임 폴더를 나눠서 쓰고 있어요.

그대로 사용하세요. .minecraft/1.21.8 mod/mods를 선택하면 바로 그 mods 폴더에 설치합니다. Fabric Loader의 실행 파일만 실제 .minecraft에 설치하고, 실행 설정의 게임 폴더는 선택한 위치로 연결합니다.

Fabric Loader 0.19.3 호환 오류가 나요.

이전 설치기 대신 위의 0.3.12 설치기로 설치하세요. Loader 0.19.5를 함께 설치하고 기존 Fabric 실행 설정도 갱신합니다. 런처를 다시 열어 Gunbed 실행 설정을 선택하세요.

무엇이 설치되나요?

Gunbed Visuals, 공용 총기 에셋, Fabric API, Nuit 네 모드와 Fabric Loader 0.19.5입니다. 원본 TaCZ 런타임은 필요하지 않습니다. 기본 마인크래프트 런처 기준이며, 별도 인스턴스 관리 런처의 설정은 자동 변경하지 않습니다.
