“의심스러운 다운로드”가 뜨나요?

현재 자동 설치기는 공인 코드 서명이 없는 개인 제작 프로그램입니다. Chrome은 다운로드가 드물거나 신뢰 정보가 충분하지 않은 EXE에 이런 경고를 표시할 수 있습니다. 이 경고만으로 악성 여부를 단정할 수 없으며, 안전하다는 보장도 아닙니다.

  1. 이 사이트와 공식 GitHub 배포본인지 확인하세요. 아래 EXE SHA-256과 받은 파일의 값을 비교할 수 있습니다.
  2. 확인 후 본인이 진행하기로 결정했다면 Chrome 다운로드 목록에서 해당 항목의 상세 메뉴를 열고 ‘의심스러운 파일 다운로드’를 선택하세요. 메뉴 문구는 브라우저에 따라 다를 수 있습니다.
  3. 확신이 들지 않으면 수동 설치 ZIP을 선택하세요. EXE를 실행하지 않고 모드를 직접 설치할 수 있습니다.

02 / AUTOMATIC INSTALL

EXE로 자동 설치.

Loader와 모드를 한 번에 준비합니다.

  1. 01

    설치기를 실행하세요

    위에서 플레이할 버전의 EXE를 받으세요. 설치 버튼을 누르면 백그라운드에 남은 Minecraft Launcher를 자동 종료합니다.

  2. 02

    쓰던 게임 폴더도 그대로

    1.21.8 mod 또는 그 안의 mods를 선택해도 됩니다. 선택한 폴더를 인식하며, 다른 버전의 폴더는 건드리지 않습니다.

  3. 03

    런처에서 Gunbed로 시작

    기존 런처를 열어 Gunbed 1.21.8을 선택하고 플레이하세요. 서버 주소는 mzs123.mcv.kr, 서버 이동은 /server gunbed입니다.

03 / MANUAL INSTALL

ZIP으로 직접 설치.

선택한 버전 1.21.8
EXE 미포함 · 모드 6개 + 한글 안내

버튼을 누르면 검증된 모드를 받아 브라우저에서 ZIP으로 묶습니다. 파일이 크므로 완료될 때까지 페이지를 열어두세요.

  1. 01

    같은 버전의 Fabric을 준비하세요

    위에서 선택한 Minecraft 버전을 지원하는 Fabric Loader 0.19.5 이상을 런처에 준비하세요. 0.19.5는 최소 요구 버전이며, 더 높은 Loader를 차단하지 않습니다. 자동 설치기는 검증된 0.19.5를 설치합니다. Fabric 공식 설치 안내 ↗ · Fabric 다운로드 ↗. 별도 런처는 해당 런처의 Fabric 설정을 사용하세요. Forge·NeoForge 프로필은 사용할 수 없습니다. 이 ZIP에는 Loader가 들어 있지 않습니다.

  2. 02

    실제 게임 폴더의 mods를 여세요

    게임과 런처를 종료한 뒤, 런처 실행 설정의 게임 디렉터리를 확인하세요. 기본은 %APPDATA%\.minecraft\mods입니다. 별도 폴더를 쓴다면 예를 들어 %APPDATA%\.minecraft\1.21.8 mod\mods를 여세요. mods 폴더가 없으면 만드세요.

  3. 03

    같은 필수 모드의 구버전만 백업하세요

    기존 Gunbed Visuals · Gunbed Assets · Fabric API · Nuit는 중복되지 않도록 mods 밖의 백업 폴더로 옮기세요. 다른 모드·설정·월드는 지우지 마세요.

  4. 04

    ZIP 속 JAR 6개를 복사하세요

    수동 설치 ZIP의 압축을 풀고, 그 안의 mods에 있는 .jar 파일 6개를 실제 mods 폴더 안에 넣으세요. JAR 자체의 압축은 풀지 말고, mods/mods처럼 폴더를 중첩하지 마세요. ZIP에 한글 설치 안내·체크섬·라이선스도 들어 있습니다.

  5. 05

    Fabric 프로필로 접속하세요

    선택한 버전의 Fabric 프로필로 게임을 실행하세요. 서버 주소는 mzs123.mcv.kr이며, 접속 후 Gunbed 또는 좀비 서버를 선택하면 됩니다. 버전이 다르면 위에서 다시 선택해 ZIP을 받아주세요. 새 모드에는 총기 텍스처가 들어 있지 않습니다. Gunbed 접속 시 필수 서버 리소스팩을 수락하고 적용이 끝날 때까지 기다리세요.

04 / GOOD TO KNOW

설치 전에 궁금한 것.

다운로드 중 504 또는 시간 초과가 나요.

기본 다운로드와 대체 경로를 순서대로 시도하며 파일 크기와 SHA-256을 검증합니다. 수동 ZIP도 같은 방식으로 모드를 확인합니다. 계속 실패하면 아래 개별 모드 링크나 GitHub 배포 파일을 이용하세요. ‘자동 설치기 ZIP’은 EXE가 든 압축 파일로, 수동 모드팩과는 다릅니다.

접근 거부(WinError 5) 오류가 났어요.

설치기 0.3.21은 기존 Gunbed 기능과 좀비 조작·외형을 함께 설치합니다. 총기 공통 에셋은 0.3.20을 유지합니다. 총기 텍스처는 모드에 포함하지 않고 Gunbed 접속 시 필수 서버 리소스팩으로 받습니다. DeltaForce 공격 모션·장전/휘두르기 음량·CrackShot 킬로그 아이콘을 수정했습니다. 새 WAT 총기·DeltaForce 근접·42Labs 투척 무기와 관전 중 유지되는 킬로그를 지원합니다. 기존 조준경 시야 수정도 포함합니다. 파일 사용 중 여부를 먼저 확인하고, 필수 모드의 읽기 전용 속성을 백업 후 처리합니다. 기존 게임 폴더를 선택해 다시 설치하세요. 경기 시작·리스폰 후 중앙 선택창에서 1번은 랜덤 무기, 2번은 즐겨찾기, 3번은 수동 선택입니다. 리스폰 후에는 4번으로 죽기 전 마지막 무기 세트를 다시 받습니다. 임시 후원 무기도 복원되며 당첨 공지는 반복하지 않습니다. 기록은 경기 종료 시 사라집니다. 골데·VSS·더블배럴은 우클릭으로 A/B 모드를 전환합니다. G36·바스티온은 우클릭으로 시즈 전개·해제하며, 해제 완료 후 움직일 수 있습니다.

총기 텍스처는 어디서 받나요?

0.3.20 공통 모드부터 텍스처와 관련 아이콘 정의는 Gunbed 서버 리소스팩으로 제공합니다. 모드 6개를 설치한 뒤 Gunbed에 접속해 필수 팩을 적용하세요. 팩은 사용자 PC에 다운로드됩니다. ItemsAdder의 압축 해제 방지를 적용했으며 완전한 추출 방지를 보장하는 기능은 아닙니다. 구버전에 이미 포함된 파일에는 이 보호를 소급 적용할 수 없습니다.

AI 자동 학습은 어떻게 작동하나요?

0.3.19부터 플레이어는 조작만 전송하며 화면 읽기를 하지 않습니다. 별도 저해상도 관전자 클라이언트가 Orchestra 플레이 시점을 재구성해 학습 자료와 연결합니다. 사용자의 실제 화면 녹화와는 차이가 있으며 바탕화면은 촬영하지 않습니다. 실제 사람의 완료 경기 자료를 모아 학습·검사하며, 개선이 확인된 모델만 다음 경기부터 사용합니다. 처음부터 학습된 사람 수준의 AI가 들어 있는 것은 아닙니다. 학습 중에는 AI전 입장이 잠시 제한됩니다.

기존 모드가 지워지나요?

다른 모드·설정·월드는 유지합니다. Gunbed Visuals, Gunbed Assets, Fabric API, Nuit, 좀비 자산, 로컬 Tissou와 모드 ID가 같은 파일만 백업 후 교체합니다. 백업은 실제 .minecraft/gunbed-backups에 저장합니다.

런처를 껐는데 실행 중이라고 나와요.

0.3.21 설치기는 백그라운드에 남아 있는 Minecraft Launcher도 자동 종료합니다. Java나 마인크래프트 게임·서버 프로세스는 강제 종료하지 않습니다. 실행 중인 게임 창도 종료한 뒤 설치하세요. 권한이 부족하다는 오류가 나오면 설치기를 관리자 권한으로 실행하세요.

버전별로 게임 폴더를 나눠서 쓰고 있어요.

그대로 사용하세요. .minecraft/1.21.8 mod/mods를 선택하면 바로 그 mods 폴더에 설치합니다. Fabric Loader의 실행 파일만 실제 .minecraft에 설치하고, 실행 설정의 게임 폴더는 선택한 위치로 연결합니다.

Fabric Loader 0.19.3 호환 오류가 나요.

이전 설치기 대신 위의 0.3.21 설치기로 설치하세요. Loader 0.19.5를 함께 설치하고 기존 Fabric 실행 설정도 갱신합니다. 런처를 다시 열어 Gunbed 실행 설정을 선택하세요.

무엇이 설치되나요?

Gunbed Visuals, 공용 총기 에셋, Fabric API, Nuit, 좀비 자산, 로컬 Tissou 여섯 모드와 Fabric Loader 0.19.5입니다. 원본 TaCZ 런타임은 필요하지 않습니다. 기본 마인크래프트 런처 기준이며, 별도 인스턴스 관리 런처의 설정은 자동 변경하지 않습니다.
